# India General Election Analysis 2024

An interactive **Power BI dashboard** for analyzing the **India General Election Results 2024** using constituency-level, state-level, party-wise, and alliance-wise data.

## 📊 Project Overview

This project presents election results through an interactive Power BI dashboard designed to explore election data at different levels.

The dashboard includes:

* Overall election overview
* State-wise demographic analysis
* Political landscape by state
* Constituency-level analysis
* Detailed constituency results
* Party-wise and alliance-wise seat analysis
* Interactive filters and navigation
* Constituency-level drill-through analysis

## 📌 Dashboard Pages

### 1. Overview Analysis

Provides a high-level view of the election results, including:

* Alliance-wise seats
* Percentage of total seats
* Party-wise seats
* NDA alliance parties
* I.N.D.I.A. alliance parties
* Other/Independent results

### 2. State Demographics Analysis

Provides state-level election information through interactive map visuals and constituency-level details.

### 3. Political Landscape by State

Allows analysis of:

* Alliance-wise seats
* Party-wise results
* Party-wise seat share
* State-level election distribution

### 4. Constituency Analysis

Provides constituency-specific information including:

* Total votes
* EVM votes
* Postal votes
* Total candidates participating
* Winning candidate
* Runner-up candidate
* Second runner-up
* Party and vote-share information

### 5. Details Grid

Provides detailed constituency-level election results in a tabular format, including candidate, party, alliance, votes, and margin information.

## ⚙️ How to Use

1. Download or clone this repository.
2. Open the `dashboard.pbix` file from the `Dashboard` folder using Microsoft Power BI Desktop.
3. Ensure the required data files are available in the `Raw Data` folder.
4. Explore the dashboard pages using the navigation and interactive filters.
5. Use the constituency and state selections to explore detailed results.

## 🎯 Project Objective

The objective of this project is to present India General Election Results 2024 in an interactive and easy-to-explore Power BI dashboard, allowing users to examine election results across states, constituencies, parties, and alliances.
